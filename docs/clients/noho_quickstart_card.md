## 핵심 기능 5가지

### 1. 출근/퇴근 체크
```
홈 화면 > 출퇴근 체크 버튼
또는 모바일 앱 > 체크인
```
- GPS 기반 출근 가능 (설정 필요)
- 지각/조퇴 자동 기록

### 2. 휴가 신청
```
HR > 휴가 신청 > New
```
- 휴가 종류 선택 → 기간 입력 → 제출
- 승인자에게 자동 알림 발송
- 승인/반려 결과 카카오 알림톡 수신

### 3. 임금명세서 확인
```
급여 > 임금명세서 > 본인 명세서 조회
```
- 매월 급여 마감 후 자동 생성
- PDF 다운로드 가능
- 카카오 알림톡으로 발행 안내

### 4. 근태 현황 확인
```
근태 > 월별 근태 현황
```
- 당월 출근일수, 연장근로 시간, 잔여 연차 확인
- 오류 발견 시 슬랙 #hrms-beta-noho 에 보고

### 5. 직원 정보 수정
```
HR > 직원 > 내 프로필
```
- 연락처, 주소 등 직접 수정 가능
- 주민등록번호 등 법적 정보는 관리자에게 요청
