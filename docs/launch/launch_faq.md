# 런칭 FAQ — 출시 후 예상 질문 30개

> 대상: 베타 신청자, 고객사 담당자, 노무사 네트워크 문의 | 작성: 2026-05-18

---

## 가격 / 비용

**Q1. 베타 기간은 정확히 얼마나 무료인가요?**  
첫 3개월 무료입니다. 베타 시작 일자 기준 90일. 이후 정식 요금제 전환 여부는 사용자가 결정하며, 강제 전환은 없습니다.

**Q2. 베타 종료 후 가격은 얼마인가요?**  
- Starter: 5만원/월 (직원 10명까지)
- Growth: 15만원/월 (직원 50명까지)
- Enterprise: 협의 (50명 초과, SLA 포함)

**Q3. 직원이 중간에 늘어나면 플랜이 자동으로 바뀌나요?**  
자동 변경은 없습니다. 직원 수가 플랜 상한에 가까워지면 운영팀이 미리 안내하고, 사용자가 결정합니다.

**Q4. 연간 결제 할인이 있나요?**  
현재 정식 요금제에 연간 결제 할인 구조는 확정되지 않았습니다. 베타 종료 시점에 안내 예정입니다.

**Q5. 사업장이 여러 개면 추가 비용이 있나요?**  
현재 플랜은 직원 수 기준입니다. 사업장 수 추가 비용은 없습니다. Enterprise 규모(50명 초과 / 다수 사업장)는 별도 협의합니다.

## 무료 기간 / 해지

**Q6. 베타 기간에 해지하면 데이터는 어떻게 되나요?**  
언제든 CSV/JSON 전체 내보내기 가능합니다. 해지 요청 후 30일 이내 데이터를 전달하고 서버에서 삭제합니다.

**Q7. 정식 전환하지 않고 베타만 쓰고 나올 수 있나요?**  
가능합니다. 강제 전환 없음, 약정 없음. 3개월 이내 언제든 중단 가능합니다.

**Q8. 환불 정책은요?**  
베타 기간은 무료이므로 환불 해당 없습니다. 정식 전환 이후 월정액 환불 정책은 별도 안내 예정입니다.

---

## 데이터 보안

**Q9. 급여 데이터가 외부로 나가지 않나요?**  
데이터는 국내 서버(Oracle Cloud, 한국 리전)에서만 처리됩니다. 해외 서버로 전송되지 않습니다.

**Q10. 고객사 데이터가 다른 회사와 섞일 가능성이 있나요?**  
없습니다. 회사/사이트 단위로 데이터를 완전 분리합니다. 멀티 테넌트 구조이지만 데이터 격리가 기본입니다.

**Q11. 2단계 인증(MFA)을 지원하나요?**  
현재 베타 기간 중 단일 비밀번호 인증. 2단계 인증(OTP/이메일)은 정식 출시 이후 적용 예정입니다.

**Q12. HTTPS는 기본인가요?**  
전 구간 HTTPS 적용됩니다. 내부 통신도 암호화됩니다.

**Q13. 사업장 담당자가 다른 사업장 데이터를 볼 수 있나요?**  
없습니다. 사업장(Branch) 단위 접근 권한 분리를 지원합니다. HR Manager에게 특정 사업장만 접근하도록 설정 가능합니다.

**Q14. 퇴직자/개인정보는 어떻게 처리하나요?**  
직원 퇴사 처리 후 데이터는 법정 보존 기간(3~5년) 동안 보유, 이후 운영자 요청에 따라 삭제합니다. 개인정보처리방침은 정식 출시 시 공개 예정입니다.

## 마이그레이션 / 데이터 이관

**Q15. 기존에 쓰던 엑셀 데이터를 가져올 수 있나요?**  
직원 마스터(이름, 입사일, 급여, 사업장)는 CSV 형식으로 bulk import를 지원합니다. 베타 기간 중 운영팀이 직접 지원합니다.

**Q16. 기존 급여 이력도 이관 가능한가요?**  
직원 마스터와 달리 급여 이력 이관은 데이터 구조에 따라 공수가 다릅니다. 건별로 검토 후 지원 여부를 안내합니다.

**Q17. 다른 HR 솔루션에서 데이터를 가져오려면 얼마나 걸리나요?**  
직원 마스터 CSV import는 1~2일(50명 기준). 과거 급여 이력 포함 시 케이스마다 다르며, 별도 일정 협의합니다.

## 멀티 사이트 / 다점포

**Q18. 사업장이 5개인데, 사업장별로 담당자를 따로 둘 수 있나요?**  
가능합니다. 사업장별 접근 권한 분리를 지원합니다. 예: 강남점 담당자는 강남점 데이터만 조회/처리.

**Q19. 사업자번호가 여러 개인 경우(법인이 다름)도 하나의 시스템으로 관리할 수 있나요?**  
Frappe Company 단위로 분리 가능합니다. 다법인 구조는 별도 설정이 필요하며, Enterprise 플랜 또는 협의 대상입니다.

**Q20. 신규 사업장(매장) 추가는 자체적으로 할 수 있나요?**  
`/app/branch`에서 직접 추가 가능합니다. Korea Workplace Profile 연결만 추가로 필요합니다.

## 모바일

**Q21. 별도 앱을 설치해야 하나요?**  
없습니다. HRMS PWA 방식으로 브라우저 접속만 하면 됩니다. 홈 화면에 추가하면 앱처럼 사용 가능합니다.

**Q22. 어떤 스마트폰에서 쓸 수 있나요?**  
안드로이드 및 iOS 최신 버전 브라우저에서 동작합니다. 기본 브라우저(크롬, 사파리) 모두 지원합니다.

**Q23. 오프라인에서도 출근 체크가 되나요?**  
현재 오프라인 모드는 지원하지 않습니다. 출근 체크 시 인터넷 연결이 필요합니다.

## 카카오 알림톡

**Q24. 임금명세서를 카카오로 보내려면 어떻게 해야 하나요?**  
카카오 비즈니스 채널 가입 + 알림톡 템플릿 등록이 사전 필요합니다. 베타 기간 중 운영팀이 연동 절차를 안내합니다. (카카오 채널 심사 기간 약 5~7 영업일 소요)

**Q25. 카카오 알림톡 비용은 별도인가요?**  
카카오 알림톡은 건당 발송 비용이 있습니다(약 8원~15원/건, 템플릿 유형에 따라 다름). HRMS 구독 요금과는 별도입니다. 50명 기준 월 400~750원 수준.

**Q26. 카카오 대신 문자(SMS)나 이메일 발송도 되나요?**  
이메일 발송은 현재도 가능합니다. SMS 발송은 추후 검토 예정입니다.

## 백업 / 장애

**Q27. 데이터 백업은 얼마나 자주 하나요?**  
일 1회 자동 백업. 백업 파일은 30일치 보관합니다. 백업 상태는 `docs/operations/backup_recovery.md` 기준으로 모니터링됩니다.

**Q28. 서버 장애 시 데이터가 손실될 수 있나요?**  
일 1회 백업 기준으로 최대 24시간 치 데이터가 복구 불가능할 수 있습니다. Enterprise SLA 협의 시 RTO/RPO 별도 설정 가능합니다.

**Q29. 서버가 다운되면 어떻게 되나요?**  
업타임 모니터링으로 5분 이내 감지 → 운영팀 알림 → 복구 작업 시작. 긴급 시 슬랙 또는 이메일(abc@winhr.co.kr) 연락.

## 기타

**Q30. 더존, 영림원 등 회계/ERP 프로그램과 연동되나요?**  
Frappe/ERPNext는 REST API를 완전 개방합니다. 더존, 영림원 등과의 공식 연동은 별도 일정이 필요합니다. 케이스별로 협의하면 가능성 검토가 가능합니다.
