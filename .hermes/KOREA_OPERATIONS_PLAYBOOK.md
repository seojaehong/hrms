# Korea HRMS Operations Playbook

## 1차 목적
- 한국 중소사업장/다지점 사업장에서 바로 시연 가능한 HRMS 베이스를 만든다.
- 법률/보험 계산은 완전자동화보다 기준값 관리 + 수동검증 보조로 시작한다.

## 운영 우선순위
1. 한국어 UI 핵심 동선
2. Employee / Company 한국 필드
3. 급여 컴포넌트 기본 세트
4. 사업장/휴가/교대 운영 템플릿
5. 법/보험 기준 업데이트 파일 유지

## 사용자에게 받을 정보
- 적용 기준일
- 회사 업종
- 사업장 수
- 상시근로자 수
- 4대보험 최신 요율/기준표
- 연장/야간/휴일근로 운영 규칙
- 연차 운영 규칙(회계연도/입사연도 기준)
- 지급항목/공제항목 실제 명칭

## 내일 점검 체크리스트
- 로그인 후 Company의 Country를 South Korea로 저장 가능한지
- Company 한국 필드가 보이는지
- Employee 한국 필드가 보이는지
- Salary Component에 한국 기본 항목이 생성되는지
- Holiday List / Leave Policy / Shift Type 샘플 생성 절차를 이어갈 수 있는지
- `.hermes/KOREA_LEGAL_RULES_INPUT.yaml`에 받은 기준을 반영할 수 있는지

## 주의
- 주민등록번호 전체 저장 금지
- 자동 계산 결과를 법률 자문 대체물처럼 제시하지 않기
- 급여 자동화는 사용자 기준표 확정 후 단계적으로 확장
