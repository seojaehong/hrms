## 2. 핵심 문제 — 노호에게 해당하는 것들

### F&B 다점포의 급여 관리 3대 고통

**고통 1: 사업장이 여러 개 → 각각 따로 계산**
- 본사(15일 마감) + 매장(10일 마감) 스케줄 다름
- 직원이 매장 이동 시 어느 사업장 소속인지 혼선
- 엑셀 파일 여러 개 관리 → 버전 충돌, 실수

**고통 2: 고용 형태 복잡 → 수당 계산 오류 위험**
- 시급제 + 정규직 + 일용직 혼재
- 연장/야간/휴일 가산수당 수작업 계산 → 임금체불 리스크
- 주 52시간 준수 여부 추적 불가

**고통 3: 임금명세서 의무화 (2023년~)**
- 근로기준법 시행령 27조의2: 7개 항목 기재 의무
- 미발송 시 과태료 500만 원/건
- 직원 40명에게 매월 수동 발송 → 공수 과다

## 3. 라이브 데모 — 5분 시나리오

**데모 URL**: https://hrms.safeclaw.kr  
**계정**: demo.hr.manager@node.pe.kr  
**비밀번호**: 미팅 직전 별도 안전 채널로 공유

### [0:00] 로그인 + 대시보드 (1분)
- 사업장별 페이롤 진행률 카드 한눈에 확인
- "노호라면 여의도점/본사/각 매장이 여기 각각 카드로 뜹니다"
- 완료 / 차단요인 / 미완 → 담당자가 어디서 막혔는지 즉시 파악

### [1:00] 급여 마감 플로우 (2분)
- 사업장 선택 → 직원 카드 클릭
- 기본급 + 연장/야간/휴일 수당 자동 산출
- 각 숫자 옆: "근로기준법 제56조 1항 기준" 법조문 링크
- 주 12시간 초과 시 빨간 경고 자동 발생
- **강조 포인트**: "법령 기준 계산 (계산 결과는 사용자 입력·설정·예외 처리에 따라 달라질 수 있음, 정확성은 운영자/노무사 검토 필요)"

### [3:00] 임금명세서 발송 (1분)
- 일괄 발송 화면 → 시행령 7개 항목 자동 체크
- 카카오 알림톡 미리보기 (직원 이름, 기본급, 수당, 공제, 실지급액)
- 클릭 한 번 → 40명 동시 발송 + 발송 완료 로그

### [4:00] 연차 현황 (30초)
- 직원별 연차 잔여 현황 (1년 미만 월차 자동 산정)
- "설정 없이 법 조문대로 계산됩니다"

## 4. NOHO 맞춤 제안

### 왜 지금, 왜 우리인가

| 이유 | 설명 |
|------|------|
| 위너스가 노호 자문사 | 급여 계산 로직을 직접 검증. 오류 발견 시 재홍님이 직접 수정 가능 |
| F&B 다점포 최적 구조 | 사업장별 격리 DB + 통합 대시보드. 사업자번호별 분리 기장 |
| 고용형태 복잡성 대응 | 시급제/일용직/정규직 혼재 시 각 계산 로직 다름 → 모두 자동화 |
| 카카오 알림톡 연동 | 직원 40명 임금명세서를 카카오로 자동 발송 (베타 진행 중, 구현 완료 시 활성화 예정) |
| 노무사 직접 운영 | "이 계산 맞아요?" → 슬랙에서 즉시 확인 가능 |

### NOHO가 얻는 것

**정량적 효과 (보수적 추정)**:
- 급여 마감 시간: 현재 추정 16시간/월 → 목표 4시간/월 (75% 절감)
- 임금명세서 발송 공수: 현재 4시간/월 → 5분/월 (자동화)
- 연장수당 오류 리스크: 연장수당 자동 계산 + 오류 탐지 알림
- 임금명세서 미발송 과태료 리스크: 임금명세서 자동 발행 (시행령 27조의2 7개 항목 포함)

**정성적 효과**:
- 사업장 추가 시 테넌트 자동 프로비저닝 설계 (실제 1회 검증 후 시간 확정)
- 신규 직원 입사 → 즉시 근태/급여 반영
- 재홍님이 노호 급여 데이터 실시간 접근 → 자문 품질 상승

## 8. 예상 Q&A

**Q. 기존 급여 데이터 가져올 수 있나요?**
A. 직원 마스터(이름, 입사일, 급여 기본정보) CSV로 import 가능합니다. 과거 급여 이력은 선택적으로 이관 가능하며 재홍님이 직접 지원합니다.

**Q. 직원들이 앱 설치해야 하나요?**
A. 아닙니다. PWA 방식이라 브라우저에서 바로 접속합니다. 카카오 알림톡은 기존 카카오 계정으로 수신됩니다.

**Q. 매장별로 급여 담당자를 따로 둘 수 있나요?**
A. 가능합니다. 사업장별 접근 권한을 분리해서, 매장 담당자는 자기 매장 데이터만 보도록 설정할 수 있습니다.

**Q. 나중에 그만하면 데이터 가져갈 수 있나요?**
A. 언제든 CSV/JSON으로 전체 내보내기 가능합니다. 데이터를 인질로 잡지 않습니다.

**Q. 보안은요?**
A. HTTPS 전 구간, 테넌트/사이트 단위 분리 구조, 관리자 2단계 인증 지원 예정 (현재는 단일 인증)입니다.

**Q. 세무사/회계 프로그램이랑 연동되나요?**
A. API 완전 개방이라 연동 가능합니다. 더존, 영림원 등과의 연동은 별도 일정 협의.
