## 2. 도입 전 문제

> 2~4개 구체적 문제를 작성합니다. 수치를 포함하면 강점이 됩니다.

### 2-1. 핵심 문제

```
(예)
- 월 급여 마감에 3일 이상 소요. 야근 반복.
- 연장수당 계산 오류로 직원 민원 월 평균 2~3건.
- 4대보험 신고 누락으로 과태료 발생 (20XX년 ___만 원).
```

### 2-2. 법규 준수 위험

```
(예)
- 최저임금 검증 수작업 → 오류 발견까지 2개월 지연.
- 연차 부여 일수 계산 오류 → 노동청 진정 1건.
```

### 2-3. 운영 비용

| 항목 | 도입 전 |
|------|---------|
| 월 급여 마감 소요 시간 | 시간 |
| 급여 관련 민원 처리 시간 (월) | 시간 |
| 외부 노무 자문 비용 (월) | 만원 |
