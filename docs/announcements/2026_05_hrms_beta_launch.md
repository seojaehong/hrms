# 한국 노무사가 만든 HR 시스템 — 5월말 베타 시작

> node.pe.kr 게시용 | 작성: 2026-05-18 | 게시 예정: 2026-05-31

---

2020년부터 위너스 노무법인을 운영하면서, 고객사 급여 마감 날이면 항상 같은 일이 반복됐다.

엑셀 여러 개를 열고, 사업장마다 파일을 따로 만들고, 연장수당을 수작업으로 계산하고, 임금명세서 40장을 문자로 하나씩 보냈다. 법 바뀐 거 반영했는지 매번 이중삼중 확인했다. 틀리면 과태료가 나오는 것들이었다.

"이걸 왜 자동화하면 안 되지?"라는 질문에서 이 프로젝트가 시작됐다.

---

## 무엇을 만들었나

**한국 노동법에 정확한 HR 통합 관리 시스템.**

페이롤, 근태, 연차, 컴플라이언스, 임금명세서 발송까지 — 전부 한국 법령 기준으로 돌아가는 시스템.

주요 기능 6가지:

1. **자동 페이롤 마감** — 사업장별 진행률 실시간 확인, 차단요인(4대보험 누락, 근태 미처리 등) 자동 감지
2. **법정 가산수당 자동 계산** — 연장(50%) · 야간(50%) · 휴일(50-100%), 주 12시간 한도 자동 검증
3. **연차 자동 산정** — 근로기준법 60조 기준, 1년 미만 월차 + 80% 출근률 룰까지 자동
4. **임금명세서 자동 발송** — 시행령 27조의2 7개 필수 항목 + 카카오 알림톡 발송
5. **컴플라이언스 진단** — 4대보험 · 임금체불 · 연장 · 직장 내 괴롭힘 등 5개 카테고리
6. **모바일 PWA** — 출근 체크(GPS) · 휴가 신청 · 명세서 조회를 앱처럼

## 왜 만들었나 — 다른 솔루션으로는 안 됐던 이유

시중에 HR 솔루션이 없는 게 아니다. 그런데 쓰면 쓸수록 공통적인 문제가 있었다.

**한국 노무법이 소수 언어처럼 취급된다.** 글로벌 HR 솔루션은 4대보험 계산 구조가 없거나 수동 입력이다. 국내 솔루션은 있긴 한데 계산 근거가 불투명하고, 업데이트가 느리고, 노무사가 "이거 맞아요?" 물어보기 어려운 블랙박스다.

**F&B 다점포, 시급제·일용직 혼재 사업장에서 약하다.** 노호(NOHO)처럼 매장 5개에 고용 형태가 3가지 이상인 곳은 기성 솔루션이 잘 맞지 않는다.

**AI 도입한다는 솔루션들의 방식이 불편했다.** 법적 판단이 필요한 영역에서 숫자(확률/점수)를 뱉는 방식은 노무사 입장에서 쓸 수가 없다. 오류 시 책임 소재가 불분명하고, 검토 없이 실행되면 위험하다.

그래서 이 시스템은:

- **AI는 보조자(assistant_only)** — 계산·집계·감지는 자동, **실행(저장/승인/발송)은 반드시 사람이 확인 후 진행**
- **학습 데이터 사용 없음** — 고객사 급여 데이터는 학습에 쓰이지 않는다
- **모든 계산에 법조문 근거 표시** — "근로기준법 제56조 1항" 이런 식으로, 감사 추적 가능
- **오픈소스 기반(Frappe/ERPNext)** — 락인 없음. 언제든 전체 데이터 내보내기 가능
- **한국 리전 운영** — 데이터가 국외 서버에 가지 않는다
