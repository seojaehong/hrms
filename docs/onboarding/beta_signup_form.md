## 섹션 3: 우선 사용 기능

| 필드명 | 유형 | 필수 | 안내 |
|--------|------|------|------|
| 가장 먼저 써보고 싶은 기능 (최대 3개) | 체크박스 | 필수 | 아래 선택지 중 최대 3개 선택 |

**선택지:**
- 페이롤 자동 마감 (사업장별 진행률, 차단요인 감지)
- 법정 가산수당 자동 계산 (연장/야간/휴일)
- 연차 자동 산정 (근기법 60조)
- 임금명세서 자동 발송 (시행령 27조의2)
- 카카오 알림톡 연동 (명세서 발송)
- 컴플라이언스 진단 (4대보험/임금체불/괴롭힘)
- 모바일 출근 체크 (GPS)
- 멀티 사업장 통합 관리
- 기타(직접 입력)

## 폼 하단 안내 문구

```
베타 신청 후 영업일 2일 이내 연락드립니다.
- 담당: 공인노무사 서재홍 (위너스 노무법인)
- 이메일: abc@winhr.co.kr

베타 조건:
- 첫 5사 선정, 3개월 무료
- 데이터 마이그레이션 지원
- 슬랙 직접 지원 (평일 4시간 이내 응답)
- 정식 전환 강제 없음

개인정보 수집 동의: 입력하신 정보는 베타 서비스 운영 및 연락 목적으로만 활용됩니다.
```

## Google Form 구현 시 설정

- 응답 스프레드시트: `HRMS 베타 신청 현황` (공유: 재홍님 + 슬랙 Zapier 연동)
- 제출 시 이메일 알림: abc@winhr.co.kr 수신
- 슬랙 알림: Zapier → `#hrms-beta-signups` 채널 (회사명/사업장수/직원수/희망 기능 요약)
- 응답자 자동 확인 이메일: 2일 이내 연락 예정 내용 포함

## Notion Form 구현 시 설정

- 데이터베이스: `베타 신청 DB` (상태 필드: 신청완료 / 검토중 / 확정 / 거절)
- 뷰: 칸반(상태별) + 테이블(전체)
- Notion → 슬랙 알림: 신규 항목 생성 시 `#hrms-beta-signups` 에 자동 포스팅

## 신청 처리 SOP (운영팀)

| 단계 | 내용 | 담당 | 기한 |
|------|------|------|------|
| 1 | 신청 확인 + 슬랙 알림 | 자동(Zapier) | 즉시 |
| 2 | 사업장 수 / 업종 / 기능 우선순위 검토 | 재홍님 | D+1 |
| 3 | 맞춤 제안서 또는 간단 이메일 발송 | 재홍님 | D+2 |
| 4 | 미팅 일정 확정 (필요 시) | 재홍님 + 신청자 | D+3 |
| 5 | 베타 5사 선정 확정 후 프로비저닝 요청 | 재홍님 → 운영팀 | 선정 즉시 |
