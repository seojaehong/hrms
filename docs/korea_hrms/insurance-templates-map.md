## 3. 근로내용확인신고서(일용직) — `근로내용확인신고_전자신고용.xlsx`

- **입력 시트명**: `서식` (다른 시트: `daily_workers_csv`, `작성방법`, `작성예시`, 코드표 2종)
- **헤더 행**: 1행
- **데이터 시작 행**: **2**
- **필수 입력 컬럼**:

| 열 | 라벨(1행) | 값 |
|----|-----------|-----|
| A | 보험구분 | 예시 `5` |
| B | 성명 | |
| C | 주민(외국인)등록번호 | 없으면 빈칸 |
| D | 국적코드 | 외국인만 |
| I | 직종코드 | 예시 `532` |
| **J~AN** | **1일 ~ 31일** | 근무일 마킹 = **숫자 1** (아래 함정 참조) |
| AO | 근로일수 | 수식 `=AQ{row}` |
| AP | 일평균근로시간 | 예시 `8` |
| AQ | 보수지급기초일수 | 수식 `=COUNT(J{row}:AN{row})` |
| AR | 보수총액(과세소득) | daily_wage 합 |
| AS | 임금총액 | 수식 `=AR{row}` |
| AT | 이직사유코드 | 예시 `3` |

### 일자 열 매핑 공식
`J`(=10번째 열)이 1일. **일자 d(1..31) → 열 인덱스 `9 + d`** → `openpyxl.utils.get_column_letter(9 + d)`.
- 1일 → J(10), 15일 → X(24), 31일 → AN(40).

### ⚠️ 함정 (US-004 생성기 필수 반영)
1. **마킹값은 반드시 숫자 `1`** (텍스트 `'1'` 금지). AQ가 `=COUNT()`인데 COUNT는 **숫자만 집계**하므로 텍스트를 넣으면 근로일수가 0이 된다.
   → prd.json US-004의 *"일자 열에 텍스트 '1'"* 서술은 **정정**: 숫자 1로 기입한다.
2. AO/AS는 수식 셀이므로 값을 하드코딩하지 말고 수식(`=AQ{row}`, `=AR{row}`)을 유지한다.
3. **템플릿 `서식` 시트에 잔존 데이터 행(2~8)이 있다** → 생성기는 기존 데이터 행을 **먼저 비운 뒤** 새 근로자를 써야 한다 (아래 PII 스캔).

## 4. PII 스캔 결과 (주민번호 패턴 `\d{6}-?\d{7}` + 실명)

| 파일 | 시트 | 발견 | 셀 좌표 |
|------|------|------|---------|
| 취득 | 서식 | **없음** (데이터 행 없음, 헤더 2행뿐) | — |
| 취득 | 전체 | 없음 | — |
| 상실 | 서식 | **없음** (데이터 행 없음) | — |
| 상실 | 작성예시 | 더미 3건 (가짜 `0000009999999`~`...997`, `홍길동`) | B3, B4, B5 |
| 근로내용확인 | **서식** | **실데이터성 7건** (RRN 패턴 + 실명: 구세희/김신화/박미복/박현식/백경택/오미자/조서윤) | **C2~C8** |
| 근로내용확인 | 작성방법 | 형식 설명 문구뿐(`1234561234567 형식`) | C4 |
| 근로내용확인 | 작성예시 | 더미 1건(`0002153168113`, `소중한`) | C2 |

> **조치**: 템플릿은 repo에 커밋 안 함(경로 참조만) → 잔존 PII가 repo에 노출되지 않는다.
> 단, **근로내용확인 `서식` 시트 행 2~8의 실데이터성 PII**는 생성기가 반드시 지운 뒤 새 데이터를 쓴다(위 함정 3). 산출물은 `.gitignore`(out/insurance/) 처리.

## 5. 재검증 스니펫 (매핑 3개 이상 셀 실측 대조)

아래를 실행하면 위 매핑 중 취득 B2·상실 A1/P1·근로내용확인 J1/AN1/AQ1(수식) 등 7개 셀을 재검증한다.

```bash
python3 - <<'PY'
import openpyxl
from openpyxl.utils import get_column_letter
T = "C:/Users/iceam/OneDrive/_10_고객/_active/급여자동화/templates/"
checks = []
```
