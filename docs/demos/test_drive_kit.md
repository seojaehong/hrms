## 5분 핵심 흐름 — 혼자 따라하기

총 소요: 5분 미만. 이 흐름만 봐도 핵심 가치를 확인할 수 있습니다.

### Step 1. 로그인 (30초)

1. `https://hrms.safeclaw.kr/hrms` 접속
2. 이메일·비밀번호 입력 → [Log In]
3. 홈 대시보드 확인

### Step 2. 직원 근태 → 가산수당 자동 계산 (90초)

1. 우측 상단 격자 아이콘 → [Korea HR Workspace] 선택
2. [한국 근태 관리] 클릭
3. 월 필터: `2026-04` 선택
4. `HR-EMP-00003` 클릭
5. 확인할 것:
   - 연장 시간·야간 시간 집계
   - 통상시급 `11,832원` 기준 자동 계산된 가산수당
   - 하단 법적 근거: "근기법 §56①②"

### Step 3. 연차 80% 출근률 경고 (60초)

1. Korea HR Workspace → [한국 연차 관리] 클릭
2. `HR-EMP-00006` 클릭
3. 확인할 것:
   - 출근률 75% (80% 미달)
   - 주황색 감액 경고 배지
   - 법적 근거: "근기법 §60④"

### Step 4. 컴플라이언스 진단 (60초)

1. Korea HR Workspace → [컴플라이언스 진단] 클릭
2. 5개 카테고리 상태 확인 (pass/warn/fail)
3. [임금] 카테고리 클릭 → HR-EMP-00007 최저임금 위험 상세 확인

### Step 5. 임금명세서 PDF (60초)

1. Korea HR Workspace → [급여명세서] 클릭
2. 직원 `HR-EMP-00003`, 월 `2026-04` 선택
3. [PDF 다운로드] 클릭 → 명세서 확인

## 10분 깊이 흐름

5분 흐름을 먼저 완료한 후 진행합니다.

### Step 6. 페이롤 마감 대시 (2분)

1. Korea HR Workspace → [페이롤 마감 대시] 클릭
2. 사업장별 마감 진행률 확인
3. `2026-04 Draft` 행 클릭
4. 차단요인 확인:
   - 4대보험 미가입 1건 (HR-EMP-00007)
   - 누락 근태 2건
5. **[마감 Submit] 버튼은 누르지 마세요** (주의사항 참고)

### Step 7. 통합 결재 인박스 (2분)

1. Korea HR Workspace → [통합 결재 인박스] 클릭
2. 대기 중 결재 목록 확인
3. 연차 신청 건 클릭 → 상세 확인
4. [승인] 클릭 → 확인 팝업 확인 → [취소] (실제 승인 하지 않음)

### Step 8. Frappe Desk — 직원 상세 (2분)

1. 우측 상단 격자 아이콘 → Frappe Desk (홈)
2. 상단 검색창에서 `Employee` 검색 → 목록 열기
3. `HR-EMP-00001` 클릭
4. 한국 전용 필드 섹션 확인:
   - `kr_tax_info`: 가족수, 원천징수 비율
   - `kr_insurance_info`: 국민연금 공단 고지액
5. 주민등록번호 필드가 **없음** 확인 (PII 차단)

### Step 9. PWA 모바일 체험 (2분)

1. 스마트폰으로 `https://hrms.safeclaw.kr/hrms` 접속
2. 동일 계정으로 로그인
3. 홈 화면 구성 확인 (모바일 최적화 UI)
4. [연차] 탭 → 잔여 연차 확인
5. Chrome → "홈 화면에 추가" 팝업 확인 (PWA 설치)

### Step 10. 급여명세서 카카오 dry-run (2분)

1. Korea HR Workspace → [급여명세서] 클릭
2. HR-EMP-00003, 2026-04 명세서 열기
3. [카카오 발송] 클릭
4. "dry-run 모드" 안내 팝업 확인
5. 발송 로그 확인 (실제 발송 없음)

## 여기 클릭하지 마세요 — 주의 화면

데모는 공유 환경입니다. 아래 동작은 다른 사용자에게 영향을 줍니다.

| 주의 동작 | 이유 |
|-----------|------|
| **페이롤 마감 [Submit] 클릭** | 마감 상태가 Draft → Submitted로 바뀌어 다른 데모 사용자가 Draft를 볼 수 없게 됩니다. |
| **급여명세서 [Submit] 클릭** | 명세서가 확정 상태로 잠겨 수정·삭제 불가능해집니다. |
| **Frappe Desk → System Settings 변경** | 시스템 전체 설정이 변경됩니다. |
| **직원 마스터 [삭제] 클릭** | 데모 데이터가 영구 삭제됩니다. |
| **새 직원 생성** | 데모 DB에 테스트 데이터가 쌓여 다른 사용자 경험에 영향을 줍니다. |
| **Frappe Desk → User → 비밀번호 변경** | 공유 계정 로그인이 불가능해집니다. |
