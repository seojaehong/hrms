## A. 제품 기본

**Q1. 이거 ERPNext인가요?**
A. 기반 프레임워크는 Frappe (ERPNext와 동일 프레임워크). 그 위에 올라간 HR 앱이 Frappe HRMS — 오픈소스입니다. 저희는 여기에 한국 법규 모듈 24개를 직접 개발해 얹었습니다.

**Q2. 기존 ERP/그룹웨어와 어떻게 다른가요?**
A. 대기업 ERP는 라이선스 비용이 수천만 원이고 한국 노동법 커스터마이징에 수개월이 걸립니다. 저희는 중소사업장 기준으로 처음부터 설계했고, 근로기준법 조문 단위로 검증한 계산 엔진을 내장합니다.

**Q3. 클라우드인가요, 온프레미스인가요?**
A. 둘 다 가능합니다. 데모는 클라우드 hosted 환경입니다. 온프레미스 설치도 지원합니다 — Frappe의 Docker 기반 배포를 그대로 사용합니다.

**Q4. 모바일에서도 쓸 수 있나요?**
A. 네. PWA(Progressive Web App)로 스마트폰 홈 화면에 설치하면 앱처럼 동작합니다. 출퇴근 체크인, 휴가 신청, 급여명세서 조회가 모바일에서 가능합니다.

**Q5. 직원 수 제한이 있나요?**
A. 없습니다. 사업장(Branch) 단위로 분리 운영이 가능하고, 다사업장 한 인스턴스에서 통합 관리가 됩니다.

**Q6. 몇 개 사업장까지 지원하나요?**
A. 현재 데모 환경은 3개 사업장 구성입니다. 실제 환경에서는 사업자등록번호 단위로 무제한 추가 가능합니다.

## B. 데이터·보안

**Q7. 데이터는 어디에 저장되나요?**
A. Frappe site 단위로 격리된 DB(MariaDB)에 저장됩니다. 회사별로 사이트를 분리하면 물리적으로 DB가 나뉩니다. 단일 인스턴스 사용 시에는 Company 단위 데이터 필터링이 적용됩니다.

**Q8. 주민등록번호는 어떻게 처리하나요?**
A. Frappe DB에는 절대 저장하지 않습니다. `resident_registration_number` 는 시스템에서 차단 PII 필드로 정의되어 있어 API 레벨에서 입력 자체를 거부합니다. 주민번호가 필요한 처리(세금신고 등)는 외부 privacy_broker를 통한 일회성 조회만 허용하고, 모든 호출에 감사 로그가 기록됩니다.

**Q9. 급여 데이터가 외부로 나가나요?**
A. 아니요. 계산 엔진은 서버 내부에서 실행됩니다. 외부 API 호출이 없습니다(AI 포함).

**Q10. 다른 직원의 급여를 볼 수 없게 막을 수 있나요?**
A. Frappe의 Role-based Permission으로 제어합니다. HR Manager는 전체 조회, 직원 본인은 본인 급여명세서만 조회하도록 기본 설정되어 있습니다.

**Q11. 데이터 백업은 어떻게 하나요?**
A. Frappe는 자동 daily 백업을 제공합니다. 클라우드 환경에서는 S3 호환 스토리지로 자동 업로드 설정이 가능합니다.

## C. AI

**Q12. AI가 자동으로 결정을 내리나요?**
A. 절대 아닙니다. AI(룰 엔진)는 이상 징후 감지·경고까지만 합니다. 마감 실행, 승인, 제출은 반드시 사람이 확인하고 클릭해야 합니다. "human_approved" 확인 단계가 설계에 내장되어 있습니다.

**Q13. 어떤 AI 모델을 사용하나요?**
A. 외부 LLM API를 사용하지 않습니다. 차단요인 감지, 이상 근태 탐지, 컴플라이언스 진단은 한국 노동법 조문 기반의 룰 엔진으로 작동합니다. ChatGPT·Claude 등 외부 서비스 연동 없음 — 인터넷 차단 환경에서도 완전히 동작합니다.

**Q14. AI가 놓치는 케이스는 어떻게 하나요?**
A. 룰 엔진이 탐지 못한 경우 HR 담당자가 수동 점검합니다. 시스템은 탐지율을 높이도록 지속 업데이트되며, 놓친 케이스는 다음 룰셋 버전에 반영됩니다.

## D. 가격·도입

**Q15. 가격은 얼마인가요?**
A. 베타 기간 중 시드 고객은 특별 혜택가로 제공합니다. 정식 출시 후 가격은 직원 수·사업장 수 기반 SaaS 구독 또는 온프레미스 라이선스 두 가지입니다. 관심 있으시면 별도 미팅에서 안내드립니다.

**Q16. 도입하려면 얼마나 걸리나요?**
A. 표준 설정(사업장 1개, 직원 20명 이하)은 1주일 내 셋업 가능합니다. 기존 급여 데이터 마이그레이션이 있으면 2~4주를 예상합니다.

**Q17. 기존 급여 데이터를 가져올 수 있나요?**
A. CSV 또는 Excel 형식으로 직원 마스터, 급여 히스토리를 임포트할 수 있습니다. 4대보험 취득일, 연차 잔여일수도 초기값 입력이 가능합니다.

**Q18. 운영을 직접 해야 하나요?**
A. 두 가지 옵션입니다. (1) 자체 운영: Frappe 서버를 직접 관리. (2) 노무법인 위너스 위탁 운영: 세팅, 급여 마감, 신고까지 노무사가 함께 합니다.

## E. 법규·계산

**Q19. 최저임금 검증이 자동으로 되나요?**
A. 네. 급여명세서 저장 시 2026년도 최저임금(시간급) 기준으로 자동 검증합니다. 위반 시 경고 표시가 뜨고 저장이 차단됩니다.

**Q20. 52시간 초과 감지가 되나요?**
A. 네. 근태 데이터를 집계해 주간 52시간 초과 여부를 체크합니다. 5인 미만 사업장은 법 적용 제외 대상으로 자동 분류합니다(근기법 §53).

**Q21. 연차 80% 출근률 계산은 어떻게 하나요?**
A. 근로기준법 §60④ 기준으로 해당 연도 소정근로일 중 실제 출근일 비율을 계산합니다. 80% 미달 시 비례 감액된 연차일수가 자동 산정되고 화면에 경고 배지가 표시됩니다.

**Q22. 중도입사·중도퇴사 일할계산은 자동인가요?**
A. 네. 입사일 기준 해당 월의 총일수 대비 근무일수 비율로 자동 일할계산합니다. 4대보험 취득 월 특례(고용보험만 공제 등)도 자동 적용됩니다.

**Q23. 외국인 근로자 처리가 되나요?**
A. 됩니다. 비자 유형별(E-9, F-4, F-6 등) 4대보험 적용 여부와 19% 단일세율 옵션을 직원 마스터에서 설정합니다. F-4 비자의 임의가입·소급 금지 등 특례도 반영되어 있습니다.

**Q24. 일용직 세금 처리는 되나요?**
A. 됩니다. 일용근로소득(6만원 이하 비과세, 1,000원 미만 세액 면제) 규정을 반영한 별도 세금 계산 로직이 있습니다.

## F. 지원·운영

**Q25. 사용법을 배우려면 얼마나 걸리나요?**
A. HR 담당자 기준 핵심 기능(출퇴근 확인, 급여 마감, 연차 관리) 숙달에 1~2일입니다. 이 데모 URL을 직접 사용해 보시면 30분 안에 핵심 흐름을 파악하실 수 있습니다.

**Q26. 오류가 생기면 어떻게 하나요?**
A. Frappe 내장 에러 로그와 알림 기능이 있습니다. 위탁 운영 계약 시 노무사 직통 지원이 포함됩니다.

**Q27. 업데이트는 어떻게 되나요?**
A. 법정 요율 변경(4대보험·최저임금·세금표) 시 업데이트 패키지를 제공합니다. 국세청 간이세액표는 매년 1월 자동 업데이트 일정입니다.

**Q28. 카카오톡 발송이 실제로 작동하나요?**
A. 급여명세서 PDF를 카카오 알림톡으로 발송하는 기능이 있습니다. 데모에서는 dry-run(발송 로그만 기록, 실제 발송 없음)으로 시연합니다. 실 계약 후 카카오 채널 연동이 필요합니다.

**Q29. 모바일 앱 스토어에서 다운로드 할 수 있나요?**
A. 별도 앱스토어 등록 없이 Chrome/Safari에서 "홈 화면에 추가"로 설치합니다. PWA 방식이라 iOS·Android 모두 지원하며 업데이트가 자동입니다.

**Q30. 데모를 지금 바로 써볼 수 있나요?**
