# 추가 기능 제안 (2026-07-11 연구) — 개인 스킬 포트폴리오 × HRMS 갭 분석

진행 중 3트랙(포괄임금 설계·역산 / 근로계약서+전자계약 / 취업규칙 룰 엔진) 외에,
개인 스킬 자산·실무 빈도·기존 로드맵과 대조해 도출한 후보. ★=권고 우선.

## ★P1. 퇴직정산 엔진 완성 (개인 스킬 「퇴직정산」 이식)
- 현재: `severance_pay.py`(퇴직금)만 존재. 갭: **퇴직소득세 계산**(근속연수공제→환산급여→차감징수 10원 버림 등 확정 로직), **건보 보수총액 정산**, **중도퇴사 연말정산**(결정세액 0 금지·차감 10원 버림·지방=결정-기납부 — 국세청 영수증 4건으로 확정된 로직).
- 가치: 퇴직 1건당 30분+ 수작업 → 에이전트 도구화 시 즉답. 스킬에 검증된 수식이 이미 있음.

## ★P2. 연차 사용촉진 통지 자동화 (§61)
- 온톨로지 노드 `연차_사용촉진` **published** — 시한 규칙이 이미 승인됨. 엔진: 근로자별 촉진 시한 계산(1년미만 특칙 포함) + 대상자 추출 + 서면 촉구문 초안 생성 + 기한 크론 알림.
- 가치: 미사용 연차수당 면책의 요건이 "시한 준수"라 자동화 효용이 큼. 전부 TDD-able.

## ★P3. 임금명세서 산정내역 분해 생성기 (§48②)
- 개인 스킬 「명세서생성」의 기본급/주휴/연장/야간/연차 분해를 엔진화 — 포괄임금 트랙(진행 중)의 설계 결과를 바로 명세서 구성항목으로 렌더. 근로감독 대응 증빙 자동화.

## P4. 중도입퇴사 일할계산 표준화
- 일할 3방식(역일/소정근로일/30일 고정) 선택형 엔진 + 사이트 정책 설정. 사업장마다 방식이 달라 수작업 오류 빈발 구간.

## P5. 감시단속적 근로자 예외 규칙 (코트라 사례 일반화)
- 승인 여부에 따른 근로시간·휴게·야간가산 적용 매트릭스. 승인 근로자도 야간 0.5 가산은 지급(§63 예외에서 야간은 제외) 같은 함정 규칙을 룰로 고정.

## P6. 노무 리스크 진단 리포트 에이전트
- 기존 `compliance_checklist` + 오늘 배선된 `search_labor_knowledge`(판정례·행정해석) 결합 — 사업장 데이터로 리스크 스캔 후 근거 인용 리포트. 영업 도구(무료 진단→수임)로도 활용.

## P7. 법정 기한 캘린더·알림
- 신고(성립·취득·상실 14일), 명세서 교부(지급 시), 촉진 시한(P2), 취업규칙 신고 등 기한 엔진 + 크론 알림. 로드맵 Phase 3 "근로내용확인신고 크론"의 일반화.

## 착수 순서 권고
P1(퇴직정산) → P2(연차촉진) → P3(명세서 분해)는 개인 스킬에 검증된 수식이 있어 이번 방식(브리지→TDD 이식→에이전트 도구화)을 그대로 재사용 가능. P6·P7은 위 자산이 쌓인 뒤가 효율적.
