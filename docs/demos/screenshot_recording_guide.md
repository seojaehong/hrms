## PII 마스킹 — 필수 체크리스트

**캡처 전 반드시 확인합니다.**

```
[ ] 주민등록번호 필드가 화면에 없음 (시스템 차단됨 — 단 확인)
[ ] 외국인 등록번호 필드가 화면에 없음
[ ] 은행 계좌번호가 화면에 없음
[ ] 주소 전체가 화면에 보이지 않음
[ ] 직원 실명이 아닌 가상 이름(홍길동, 김철수 등)임을 확인
[ ] 실제 사업자등록번호가 아님을 확인
[ ] 로그인 계정(이메일/비밀번호)이 화면에 보이지 않음
```

**위 항목 중 하나라도 화면에 보인다면 캡처하지 마세요.**
실수로 캡처했다면 즉시 삭제 후 편집 도구에서 블러 처리.

### 블러 처리 방법

- Windows: Snipping Tool → 그림판 3D → 블러 도형 덮기
- Mac: Preview → 도구 → 주석 → 직사각형 채우기
- 영상: DaVinci Resolve → Blur 이펙트 적용

## 스크린샷 체크리스트

각 스크린샷 저장 전 확인:

```
[ ] 해상도: 1920×1080 이상
[ ] 브라우저 주소창에 올바른 URL 표시
[ ] 북마크 바 숨김
[ ] 불필요한 탭 닫힘
[ ] 시스템 시계·알림 노출 확인 (날짜 노출 OK, 개인 알림 NG)
[ ] PII 마스킹 체크리스트 완료
[ ] 파일명 규칙 준수: phase##_description.png (예: phase03_payroll_dashboard.png)
```
